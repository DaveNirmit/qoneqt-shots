# Qoneqt Shots

One sentence in. A Shot out.

Qoneqt Shots turns a short idea into a ready-to-post vertical (9:16) video for the Qoneqt feed. A language model running on your own computer writes the script, Gemini directs the scenes and creates an image for each one, a voice narrates it, and FFmpeg renders a captioned MP4. Built for the Qoneqt hackathon.

## Quick start (Windows, PowerShell)

Requirements: Node.js 20 or newer, and about 3 GB of free disk space.

1. Install Ollama (runs the local script-writing model). Open PowerShell and run:

   ```powershell
   irm https://ollama.com/install.ps1 | iex
   ```

   If that fails with a connection error, run this first and retry, or download the installer from https://ollama.com/download:

   ```powershell
   [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
   ```

   Close and reopen the terminal afterwards, then check it works:

   ```powershell
   ollama --version
   ```

2. Clone the project and install dependencies:

   ```powershell
   git clone https://github.com/DaveNirmit/qoneqt-shots.git
   cd qoneqt-shots
   npm install
   ```

   If PowerShell refuses to run `npm` ("running scripts is disabled"), run this once:

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```

3. Download the local model (about 1 GB, one time) and verify it:

   ```powershell
   npm run setup
   ```

4. Optional but recommended: add a free Gemini API key so scenes and images are generated by AI. Create a file named `.env` in the project folder:

   ```
   GEMINI_API_KEY=your-key-here
   GEMINI_VIDEO=off
   ```

   Get a key at https://aistudio.google.com/apikey. The free tier covers scene writing and image generation. `GEMINI_VIDEO=off` keeps the paid Veo video model switched off; scenes get motion locally instead.

5. Start the studio:

   ```powershell
   npm run start
   ```

   It opens http://localhost:5173 in your browser. The backend runs on http://127.0.0.1:3001.

macOS and Linux work the same way with `ollama` installed from https://ollama.com/download and the same `npm` commands in a terminal.

## How a Shot is made

1. **Idea.** Describe the video in a sentence or two, pick a length (15 to 60 s), a tone and a narration voice.
2. **Script.** The local model (Qwen 2.5 1.5B through Ollama) turns your words into a brief: title, hook, key points, caption and hashtags. Choose 2 to 5 scenes and press Generate. Gemini directs each scene (on-screen text, narration, image prompt) and creates a 9:16 image for it. Edit anything.
3. **Video.** FFmpeg adds narration, captions and camera motion and exports a 720 x 1280 H.264 MP4. Download it and copy the caption for Qoneqt.

Everything you make is saved in the Library.

## What runs where

| Part | Runs | Needs internet |
|---|---|---|
| Script brief | Locally, Ollama (`qwen2.5:1.5b`) | No |
| Scene direction and images | Gemini API (free tier) | Yes. Without a key: local model and stock image search |
| Narration | edge-tts neural voices, Windows voices as offline fallback | Yes for neural voices |
| Video render | Locally, bundled FFmpeg | No |
| Trends | Hacker News, BBC and GDELT public feeds | Yes |
| Trending on Qoneqt | `server/data/qoneqt-trends.json` (curated; Qoneqt has no public trends API yet) | No |

Your Gemini key is read only from `.env`, which is ignored by git.

## Commands

| Command | What it does |
|---|---|
| `npm run start` | Checks everything, starts backend and frontend, opens the browser |
| `npm run setup` | Downloads and verifies the local model |
| `npm run doctor` | Prints a diagnostic of Ollama, voices, FFmpeg and disk space |
| `npm run dev` | Starts backend (3001) and frontend (5173) without the checks |
| `npm run build` | Builds the frontend into `dist/` |

## Troubleshooting

- **"Ollama not running" in the System page.** Start it with `ollama serve` in a terminal, or open the Ollama app, then press "Re-run checks".
- **"Model not installed".** Run `npm run setup`.
- **Gemini "Key rejected".** Check `.env` for typos and restart `npm run start`. Keys are created at https://aistudio.google.com/apikey.
- **Scene image failed.** The free tier has a per-minute limit. Wait a few seconds and press "New image". If no key is set, images come from stock search and need internet.
- **Port 3001 or 5173 in use.** Stop the other process, or start with `PORT=3005 npm run start`.
- **No narration audio.** Neural voices need internet. Offline Windows voices are used automatically when they are unavailable.
